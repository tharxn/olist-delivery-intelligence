# Dataset attribution and derived outputs

Source: **Brazilian E-Commerce Public Dataset by Olist**.

Publisher: Olist, via https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce.

The publisher metadata observed during download identifies the license as **CC BY-NC-SA 4.0**: https://creativecommons.org/licenses/by-nc-sa/4.0/.

The source data and the derived data tables, analytical figures and report outputs remain subject to those terms, including attribution, noncommercial use and ShareAlike. The raw archive is not redistributed in the project ZIP. Source provenance is recorded in `reports/source_metadata.json`.

Changes made: selected eight source tables; cast types; translated category labels using the supplied translation; reduced multiple reviews to one deterministic latest review per order; aggregated items and payments; calculated delivery, review and prioritization metrics; generated summaries and visualizations. No original observations were replaced with generated data.
